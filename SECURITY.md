# Security policy

## Supported versions

Security fixes are provided for the most recent GitHub release.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting for this repository when
available. Do not open a public issue for a vulnerability that exposes users,
network services, pairing data, or a practical attack.

For ordinary non-sensitive bugs, use the bug-report issue template. Remove
public IP addresses, device identifiers, pairing records, and unrelated log
content before submitting diagnostics.

LocalPlay is intended only for trusted private networks. Do not expose its
receiver ports directly to the public internet.
